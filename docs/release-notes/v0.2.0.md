## Harbor 0.2.0 — находит то, что уже установлено на ПК

- **Поиск установленного.** При запуске и после каждой синхронизации Harbor ищет программы твоих репозиториев: в «Приложениях Windows» (по ссылке на репозиторий в записи или по имени, в том числе с номером версии) и в папках `Programs`, `Program Files`, «Загрузки», «Рабочий стол». Только чтение: ничего не запускается и не меняется.
- **На карточке:** «Установлено на ПК · версия · источник», путь во всплывающей подсказке; если на GitHub версия новее — «На ПК 0.5.0, доступно v0.8.0», кнопка «Обновить до …» и попадание в «Обновить всё».
- **Кнопки:** «Запустить», «Папка», «Удалить программу» (штатный деинсталлятор Windows, с подтверждением).
- Фильтр «Скачанные» стал «Установленные» (скачанное Harbor'ом и найденное на ПК), в строке итогов — «Найдено на ПК», в «Настройках» — кнопка «Найти установленные на ПК», новые находки пишутся в журнал.

Ограничение: у программ, найденных только по папке, версия неизвестна (сравнение с релизом для них не делается); если у программы нет записи в «Приложениях» и она лежит в нестандартной папке, Harbor её не увидит — скачай её через Harbor или добавь запись установщиком.

## Файлы релиза

| Файл | Что это |
| --- | --- |
| `Harbor-Setup.exe` | установщик (тот же исполняемый файл) |
| `Harbor.exe` | портативная версия, её же скачивает самообновление |
| `SHA256SUMS.txt` | контрольные суммы |

Файлы **не подписаны**: SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае».
