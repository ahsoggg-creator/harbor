## Harbor 0.1.0 — все твои проекты с GitHub в одном окне

Первый выпуск: список репозиториев аккаунта подтягивается сам, программы из релизов скачиваются, обновляются и удаляются одной кнопкой.

- **Автосписок.** Репозитории и их последние релизы подтягиваются при запуске и по таймеру (по умолчанию раз в 10 минут, `F5` — сразу). Условные запросы (ETag) не тратят лимит GitHub API; токен берётся из `gh auth token` или вводится вручную — тогда видны и приватные репозитории.
- **Скачать.** Файл релиза с прогрессом и отменой; если файлов несколько — выбор из списка (по умолчанию установщик). SHA-256 проверяется по `SHA256SUMS.txt` из релиза. Для репозиториев без релизов — исходники (zip).
- **Скачанное.** «Запустить», «Папка», «Удалить» (файлы с диска, с подтверждением). **Удалить из списка** скрывает карточку, не трогая файлы; вернуть — фильтр «Скрытые».
- **Обновления.** Бейдж «доступно обновление», «Обновить» и «Обновить всё», автоскачивание (по желанию), старые версии удаляются.
- **Удобство.** Поиск `Ctrl+F`, фильтры (с релизом, скачанные, с обновлением, избранные, приватные, скрытые), сортировка, плитки и список, избранное, «Что нового», добавление любого публичного репозитория по ссылке, журнал событий, экспорт списка в Markdown.
- **Установщик без прав администратора:** `Harbor-Setup.exe` (или `--install`) ставит в `%LOCALAPPDATA%\Programs\Harbor`, добавляет ярлыки и запись в «Приложения и возможности»; `--uninstall` убирает всё. Harbor сам находит свои новые релизы и обновляется.

## Файлы релиза

| Файл | Что это |
| --- | --- |
| `Harbor-Setup.exe` | установщик (тот же исполняемый файл) |
| `Harbor.exe` | портативная версия, её же скачивает самообновление |
| `SHA256SUMS.txt` | контрольные суммы |

Файлы **не подписаны**: SmartScreen может показать предупреждение — «Подробнее» → «Выполнить в любом случае». Проверить файл можно по `SHA256SUMS.txt`.

Не проверялось на реальных данных: загрузка очень больших файлов по нестабильному каналу, GitHub Enterprise, аккаунты с более чем 1000 репозиториев.
